- Every control now shows its state: keyboard focus draws a visible ring, disabled buttons look disabled, buttons have a pressed beat, and pinned snippets show a filled pin. / 所有控件现在都显示自己的状态：键盘焦点有可见的圈，禁用的按钮看起来就是禁用，按下有反馈，钉住的条目图钉变为实心。
- Keyboard users can now reach and start the hotkey capture boxes with Enter/Space, and confirm what is actually focused everywhere. / 键盘用户现在可以用回车/空格进入并启动快捷键录入框，各处都能看清焦点在哪个控件上。
- Narrow panel rows drop the category chip so the snippet name stays readable; the preview area sizes itself to the screen you are on. / 面板变窄时行内不再显示分类小牌，条目标题保持可读；预览区高度按所在屏幕自适应。
- Right-to-left languages (Arabic etc.) get mirrored tray and context menus. / 阿拉伯语等从右往左的语言，托盘与右键菜单方向已随语言镜像。
- The editor marks the current line with a thin accent bar at the left edge instead of a full-width wash that looked like a stray scrollbar. / 编辑器改用左缘一条细色带标记当前行，不再是容易被误认为滚动条的整行底纹。
- Text fixes across 16 languages: browsing no longer says "7 matches" (it says 7 items), Traditional Chinese and Korean got corrected terminology, and several languages no longer advertise pinyin search that doesn't apply to them. / 16 种语言文案修正：浏览时不再显示"7 个匹配"（改为 7 条），繁中、韩文术语纠正，多个语言不再提示对其不适用的拼音搜索。
