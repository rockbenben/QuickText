- The long-text preview folds into a one-line strip instead of squeezing the results list, and expands on click or Ctrl+Space. / 长正文预览收成一条摘要带，不再把结果列表压扁；点它或按 Ctrl+Space 才展开。
- The hotkey capture keeps the Win key, so Win+S records the combination the UI promises instead of just "S". / 组合键录入认得 Win 键了：Win+S 会被记成完整组合，而不是只记下 S 然后继续催你按修饰键。
- The call-out hotkey and the capture hotkey can no longer hold the same combination (the second one used to fail with a misleading "in use by another program"), and clearing the call-out key falls back to the default instead of locking you out of your own app. / 呼出键与采集键不再允许填同一个组合（此前第二个必然注册失败，报错还甩锅"被别的程序占用"）；清空呼出键会落回默认值，而不是把自己锁在门外。
- An empty name disables the OK button instead of closing the dialog and doing nothing, and surrounding spaces are trimmed so " 周报" and "周报" are not two categories. / 空名字现在直接禁用"确定"按钮，不再是对话框关掉、什么都没发生；首尾空格也会被去掉，" 周报"和"周报"不会成了两个分类。
- The settings page now says how an abbreviation expands (space, Tab, or Enter) and how to undo it (backspace), in all 18 languages. / 设置界面现在写清了缩写打完之后按什么才展开（空格、Tab 或回车）、按错了怎么收回（退格），18 种语言都补上了。
- The scrollbar thumb is thinner and is now visible in the light theme, where it used to be effectively invisible. / 滚动条滑块收细了，浅色主题下也看得见了，此前那个滑块基本等于没有。
