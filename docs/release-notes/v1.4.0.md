- The search index is now built on a background thread, so startup no longer sits through the pinyin dictionary load before the panel can open. / 搜索索引改到后台线程构建，启动时不用再干等拼音词典加载完才唤出面板。
- If the index fails to build, the tray now says so, instead of the search panel quietly returning nothing. / 索引构建失败时托盘会给出说明，不再是搜索面板安安静静地什么都搜不到。
- Long translations now wrap instead of being cut in half: checkbox labels, the hint under the search panel, and the trash dialog's buttons all fit. / 长翻译现在会换行，不再被拦腰切掉：复选框标签、搜索面板下方的提示、回收站的按钮行都放得下了。
- Buttons that destroy something now look like it: the confirm key on a delete, an overwrite, or an empty trash is red, matching the trash dialog. / 会毁掉东西的按钮现在长得也像会毁掉东西：删除、覆盖、清空回收站的确认键改成红色，与回收站对话框一致。
- The non-resizable dialogs now stay on screen. Long variable lists and long messages are capped to the monitor's work area and scroll, with the title and buttons pinned. / 不能改大小的对话框不再长出屏幕：变量多、消息长时按所在显示器的工作区封顶并可以滚动，标题和按钮固定不动。
- Opening a window no longer flashes white in the dark theme, and a window that Windows refuses to foreground is still brought in front of the program that blocked it. / 深色主题下开窗不再闪白；被 Windows 拒绝抢前台的窗口，也会被提到挡路的那个程序前面。
- The tray icon now comes from a maintained library, and failures that used to vanish (a failed daily backup, a failed index build) are written to a log file next to your settings. / 托盘图标换用仍在维护的库；以前会人间蒸发的一次失败（每日备份失败、索引构建失败）现在会写进与设置同目录的日志文件。
- Releases now ship a SHA256SUMS.txt and a GitHub build attestation, so you can check the download came out of this repository's build. / 每个版本现在附带 SHA256SUMS.txt 和 GitHub 构建证明，可以据此确认下载的确实出自本仓库的构建。
