## 中文

如果你使用管理员自启，这次更新值得升级。安装包的权限要求也有变化，请按你的电脑权限选择下载方式。

### 修复

- 管理员账户以普通权限打开 QuickText 时，也能启用管理员自启；便携版和放在 Program Files 之外的程序同样支持。便携版启用后仍会在本机留下计划任务。
- 切换普通自启与管理员自启失败时，会尝试恢复原来的自启设置，减少重复或丢失自启项的情况。

### 变更

- 设置页调整了侧栏宽度、分组间距和分隔线，并为分类增加图标，便于查找选项。
- 安装包默认安装到 Program Files，安装时需要管理员授权；如果你没有管理员权限，可下载便携 ZIP，解压后运行。

[完整改动](https://github.com/rockbenben/QuickText/compare/v1.5.0...v1.5.1)

## English

This update is worth installing if you use elevated autostart. The installer also has a different permission requirement, so choose a download that suits your PC.

### Fixed

- Administrator accounts can enable elevated autostart even when QuickText is running without elevation. Portable copies and copies outside Program Files are also supported. Enabling this for a portable copy still creates a scheduled task on that PC.
- If switching between normal and elevated autostart fails, QuickText attempts to restore the previous startup settings to reduce duplicate or missing startup entries.

### Changed

- Settings has revised sidebar widths, group spacing and dividers, plus category icons to help you find options.
- The installer now defaults to Program Files and requires administrator approval. If you do not have administrator access, download a portable ZIP, extract it and run QuickText.
