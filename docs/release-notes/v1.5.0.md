## 中文

这次更新适合需要在多台 Windows 电脑间使用 QuickText，或经常编辑、同步文本库的你。

### 新增

- 提供 x64 安装包，以及 ARM64 自包含和精简便携版。检查更新仍默认关闭；开启后会下载并校验与你运行的程序架构匹配的新版，解压到独立目录，由你手动替换旧版。
- 开机自启可选以管理员身份运行，方便向提权窗口粘贴。需要管理员账户，且程序位于 Program Files 下受保护的目录；启用时可能需要一次 UAC 授权，便携模式也会在本机留下计划任务。
- 设置改用侧栏分类，小屏幕上保存按钮保持可见。管理器增加当前分类筛选、正文首行预览、Ctrl+F 定位筛选和 Ctrl+S 保存；清空筛选会保留编辑草稿。

### 修复

- 保存失败时保留草稿，文本库重新加载后阻止旧编辑内容覆盖新数据；备份导入、回收站恢复和切换数据目录也增加了校验与失败保护。
- 开启缩写后，正常输入捷克语等语言的死键重音字符不再受干扰；缩写遵循仅复制设置，发送时切换窗口会取消尚未执行的按键，减少误输入。

[完整改动](https://github.com/rockbenben/QuickText/compare/v1.4.2...v1.5.0)

## English

This update is useful if you use QuickText across Windows PCs or regularly edit and sync your snippet library.

### Added

- An x64 installer and ARM64 portable builds, with or without the bundled runtime. Update checks remain off by default. When enabled, they download and verify a build matching the running app's architecture, then unpack it into a separate folder for you to replace the old version manually.
- Start with Windows can now run QuickText as administrator for pasting into elevated windows. This requires an administrator account and a protected program directory under Program Files. Enabling it may require one UAC approval; portable mode also leaves a scheduled task on that PC.
- Settings now use sidebar categories and keep Save visible on short screens. The Manager adds filtering within the current category, first-line previews, Ctrl+F to focus the filter, and Ctrl+S to save. Clearing the filter preserves your draft.

### Fixed

- Failed saves preserve your draft, and library reloads prevent stale edits from overwriting newer data. Backup imports, trash restores, and data-folder changes also gain validation and failure protection.
- Abbreviations no longer interfere with normal dead-key accents, including Czech characters. They also respect copy-only output, and switching windows during output cancels pending keystrokes to reduce misplaced input.
